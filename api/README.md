# `/api`

This directory contains all API definitions, handlers used across the Rapida Voice Orchestration Platform.
It provides a structured, reliable, and observable interface for interacting with Rapida’s core services.


 assistant-api      # Manage assistants and voice behavior
 document-api       # Knowledge docs, embeddings, retrieval
 endpoint-api       # Webhooks, callbacks, external events
 integration-api    # Third-party integrations
 web-api            # Web dashboard and internal UI APIs

The Web API permission-to-operation inventory is documented in
[`web-api/README.md`](web-api/README.md).
